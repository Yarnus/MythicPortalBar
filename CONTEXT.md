# Domain Glossary

## Season Dungeon

A dungeon in Blizzard's current Mythic+ season pool.

## Dungeon Item

The interactive bar item representing one Season Dungeon.

## Highest Completed Level

The highest keystone level represented by the character's best in-time or overtime seasonal run for a dungeon. Timing the run is not required.

## Dungeon Score

The current character's Blizzard-provided seasonal score for one dungeon.

## Portal Ability

A dungeon teleport spell learned by the current character.

## Portal Learned

The character knows the dungeon's Portal Ability. This does not imply that the spell is off cooldown or currently castable.

## Season Data Unavailable

The game client has not supplied a valid season dungeon pool or character records. This state is distinct from a zero result.

## Position Preference

The account-wide saved screen position of the dungeon bar.

## Appearance Preferences

The account-wide visual choices for the dungeon bar, including scale, opacity, dimensions, spacing, and typography.
